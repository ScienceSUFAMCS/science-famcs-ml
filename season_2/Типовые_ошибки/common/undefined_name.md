**Что не так.** В коде используется переменная, функция или класс, которых нет
ни в одной ячейке: не импортированы или создавались в ячейке, которую потом
удалили.

**Почему это важно.** Сохранённые выводы это маскируют: под ячейкой висит
результат, полученный когда-то давно, и работа выглядит рабочей. Но при
`Restart Kernel & Run All` она упадёт с `NameError` — то есть нарушено главное
требование всех заданий курса. Проверяющий не сможет ни повторить результат,
ни доверять числам в ноутбуке.

**Как надо.** Сделать `Kernel → Restart Kernel and Run All Cells` и починить
первую же упавшую ячейку. Чаще всего это одно из двух:

```python
# забыли импорт
from sklearn.metrics import mean_squared_error, r2_score

# или удалили ячейку, где переменная считалась, — верните расчёт
acc_raw = accuracy_score(y_test, knn_raw.predict(X_test))
```
