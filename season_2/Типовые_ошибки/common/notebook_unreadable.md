**Что не так.** Файл не разбирается как ноутбук: он пустой (0 байт), повреждён или
это вообще не `.ipynb` — например, markdown-файл, которому поменяли расширение.

**Почему это важно.** Такую работу невозможно ни запустить, ни проверить. Для
проверяющего она равносильна несданной.

**Как надо.** Откройте файл в Jupyter у себя и убедитесь, что он открывается.
Проверьте, что закоммитили именно ноутбук, а не пустышку:

```bash
git add hw02_eda/hw02_eda.ipynb
git status          # файл должен быть в списке, размер > 0
git commit -m "hw02: EDA"
git push
```

Частая причина — коммит до сохранения ноутбука или конфликт слияния,
оставивший в файле маркеры `<<<<<<<`.
