**Что не так.** Ни у одной ячейки нет номера выполнения: ноутбук сохранён,
но ни разу не прогонялся. Выводов, графиков и метрик в файле нет.

**Почему это важно.** Код без единого запуска не проверяем: неизвестно, работает
ли он вообще и что он выдаёт. В задании прямо сказано, что ноутбук должен
выполняться сверху вниз без ошибок.

**Как надо.** Перед коммитом всегда делать `Kernel → Restart Kernel and Run All
Cells`, дожидаться конца и только потом сохранять:

```bash
# то же самое из терминала
jupyter nbconvert --to notebook --execute --inplace hw02_eda/hw02_eda.ipynb
```

После этого у каждой ячейки появится номер, а под ней — вывод.
