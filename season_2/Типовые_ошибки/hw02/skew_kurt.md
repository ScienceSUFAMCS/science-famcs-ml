**Что не так.** Не посчитаны `var`, `skew`, `kurt` — пункт для самостоятельного
изучения из задания.

**Почему это важно.** Асимметрия (skewness) показывает перекос распределения:
при сильном правом хвосте (цены, зарплаты, пробег) линейным моделям обычно
помогает логарифмирование таргета. Эксцесс (kurtosis) говорит о тяжести хвостов,
то есть о том, насколько часто встречаются экстремальные значения.

**Как надо.**

```python
print(df["Price"].var(), df["Price"].skew(), df["Price"].kurt())
# skew > 1 — сильный правый хвост, есть смысл в np.log1p
```
