**Что не так.** Задание требовало сгенерировать 2–3 новых признака, и этого
не сделано (или сделано формально, без объяснения смысла).

**Почему это важно.** Feature engineering обычно даёт больший прирост качества,
чем смена модели. Отношение двух колонок, месяц из даты, объединение редких
категорий в «Other» — простые операции, которые приносят модели информацию,
которую она сама из сырых столбцов не извлечёт.

**Как надо.** Создать признаки и в тексте объяснить гипотезу за каждым:

```python
df["km_per_year"] = df["KM"] / df["Age"].clip(lower=1)   # интенсивность эксплуатации
df["is_rare_model"] = df["Model"].map(df["Model"].value_counts()) < 10
```
